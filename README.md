# 犬か。犬以外か。

画像を見て「犬」か「犬以外」かを制限時間内に押すだけの反射ゲーム。ひっかけ画像（唐揚げに見えるトイプードル等）が主役。説明不要、1プレイ5分。夜中のBBQ名義、PLiCy公開。

## 基本ルール
- 画面中央に画像1枚。制限時間内に判定。時間切れは誤答。
- 判定後0.3秒だけ「DOG! 🐕」「NOT DOG!」を表示して即次へ。解説なし。
- ライフ3。誤答・時間切れで−1、0でゲームオーバー。
- 曲はBGMのみ。拍とは同期させない。

## 構成（一本道・全60問）

| 面 | 制限時間 | ひっかけ率 | 問数 |
|---|---|---|---|
| 1 入門 | 2.0秒 | 3割 | 12 |
| 2 なんとなく犬 | 1.5秒 | 6割 | 12 |
| 3 茶色い奴ら | 1.0秒 | 8割 | 12 |
| 4 尻 | 0.75秒 | 9割 | 12 |
| 5 DOG HELL | 0.5秒 | 10割 | 12 |

レベル選択なし。全60問クリアで完全クリア画面。

## スコア
- 正解 +100
- 早押しボーナス 残り時間の割合×100（最大+100）
- コンボ倍率 10連続ごとに+0.5（10連×1.5、20連×2.0、上限×3.0）
- 誤答・時間切れでコンボ消滅

## 操作
- PC：左クリック／←／Z／Space＝犬、右クリック／→／X＝犬以外。contextmenu無効化。
- スマホ：画面左半分タップ＝犬、右半分＝犬以外。開始前のみ薄いガイド表示。
- pointerdownで統一実装。

## 画面
- タイトル：タイトル＋「タップで開始」のみ。
- プレイ中：画像、残り時間バー、ライフ、コンボ数（10の倍数で強調）、面名。
- ゲームオーバー／クリア：スコア、到達面、間違えた画像一覧（「あなたはこれを犬以外だと思いました」形式）、リトライ1タップ。
- ランキング・称号は後回し。

## 画像管理
- ファイル名に正解を埋める：dog_012_poodle.webp / not_045_karaage.webp
- images.csv：filename, answer(dog/not), level(1-5), trick(1-3)
- プロトタイプは犬10枚・犬以外10枚から。素材はMidjourney生成。
- 元PNGは raw/ に置き、webp変換後のみコミット。

### raw/ の処理
元画像は `raw/<面>/<answer>[_t<trick>]_<slug>.png` の形で置く。`answer` は dog / not、trick 省略時は 1。面はファイル名に `_l<N>` を付けても指定できる。

```
raw/1/dog_poodle.png         -> 面1 / 犬     / trick=1
raw/3/not_t3_karaage.png     -> 面3 / 犬以外 / trick=3
raw/dog_l5_t3_oshiri.png     -> 面5 / 犬     / trick=3
```

```sh
pip install Pillow
python3 tools/process_raw.py            # 変換して images.csv を更新
python3 tools/process_raw.py --dry-run  # 確認だけ
```

webp（既定 512px 正方形・品質82）を `img/` に出し、`images.csv` を書き直して、面ごとの問数・ひっかけ率を README の構成表と突き合わせて表示する。通番は既存 `images.csv` から引き継ぐので再実行しても既存画像の番号は動かない。出力が元画像より新しければ変換を飛ばす（`--force` で強制）。

## 技術
- 単一HTML/JS、PLiCy制約準拠（容量・外部通信なし）。
- 画像はwebp、正方形、事前プリロード。
